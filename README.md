# Discord-бот: конвертация изображений в GIF

## Возможности

Бот превращает изображение в GIF тремя способами вызова:

- `/togif` — слэш-команда с параметрами `attachment` (прикреплённая картинка) и `url` (ссылка на картинку **или** на сообщение Discord).
- `!togif [ссылка]` (алиас `!gif`) — обычная команда с префиксом `!`.
- Упоминание бота (`@БотИмя`) в сообщении.

Источник картинки определяется в следующем порядке:
1. Явно переданное вложение/ссылка в самой команде.
2. Вложение к сообщению с командой/упоминанием.
3. Ссылка на другое сообщение Discord (вида `https://discord.com/channels/.../.../...`) в тексте — картинка берётся из него.
4. Обычная ссылка на изображение в тексте.
5. Ответ (reply) на сообщение — картинка берётся из него.

Если исходное изображение уже анимированное (GIF/WEBP), все кадры сохраняются в результирующем GIF.

## Установка

1. Создайте приложение и бота в [Discord Developer Portal](https://discord.com/developers/applications).
2. В разделе **Bot** включите **Message Content Intent** (обязательно для чтения текста сообщений и упоминаний).
3. Пригласите бота на сервер по OAuth2 URL с правами: `Send Messages`, `Read Message History`, `Attach Files`, `Use Slash Commands`.
4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Создайте файл `.env` рядом с `bot.py`:

   ```
   DISCORD_TOKEN=ваш_токен_бота
   ```

6. Запустите бота:

   ```bash
   python bot.py
   ```

Слэш-команда `/togif` синхронизируется автоматически при старте (`on_ready`). Глобальная синхронизация может занять до часа при первом запуске — для мгновенного теста можно временно синхронизировать команды для конкретного сервера (`bot.tree.sync(guild=...)`).

## Примечания

- Для ссылок на сообщения бот должен иметь доступ к соответствующему каналу.
- GIF из статичного изображения содержит один кадр (это ожидаемо — GIF без анимации).
- При необходимости лимит размера файла для отправки регулируется правами/уровнем буста сервера — Discord ограничивает размер вложений.
